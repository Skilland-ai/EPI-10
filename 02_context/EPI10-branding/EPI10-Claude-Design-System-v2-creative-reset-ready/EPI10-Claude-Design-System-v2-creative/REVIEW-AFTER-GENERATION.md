# Review after generation

Do not feed this file into Claude during setup. It is a human review checklist.

## First-pass questions

1. Does the system feel authored or assembled from a generic template?
2. Is there a clear art direction beyond navy + cyan?
3. Has the model created an interesting typographic voice?
4. Can the system alternate editorial storytelling with functional UI?
5. Is photography structurally important rather than decorative?
6. Are the components recognizably related without all having the same shape?
7. Does it avoid equal four-column card grids as the default answer?
8. Does it feel premium without imitating luxury cosmetics?
9. Does it feel scientific without resembling a hospital or laboratory website?
10. Could it support a landing page, questionnaire, report and presentation without becoming generic?

## Immediate rejection conditions

- Visual bugs such as repeated image bands, broken crops or unreadable overlays.
- A system that is effectively one landing page rather than reusable foundations.
- Generic startup gradients, glassmorphism or AI-neural-network clichés.
- A card library with no editorial language.
- More visual emphasis on hereditary risk than on wellbeing and opportunity.
- Use of the old multicolor corporate identity.
- Claims or statistics not present in the source material.

## What to send back for review

- Full design-system overview at 100% zoom.
- Foundations: colors, type, spacing and image treatment.
- Buttons, navigation, cards/panels, forms and sensitive-result patterns.
- One desktop and one mobile application example.
- The model and mode used for the generation.

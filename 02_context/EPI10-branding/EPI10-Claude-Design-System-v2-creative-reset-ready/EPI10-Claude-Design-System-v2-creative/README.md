# EPI10 Claude Design System — Creative Reset v2

This is an intentionally open, assets-first source package for a clean Claude Design experiment.

## Purpose

The previous package included a complete React specimen, exact tokens, a font choice, named components and validation prompts. Claude treated that specimen as the answer and reproduced its structure too literally.

This version removes those anchors. It provides enough strategic truth to protect the brand while leaving art direction, typography, composition, component geometry, motion and visual language open to the model.

## Recommended setup

1. Create a new organization or a genuinely new design system. Do not Remix the previous system.
2. Paste the two texts from `SETUP-COPY.md`.
3. Leave GitHub, local code and `.fig` empty.
4. Upload only the three files inside `UPLOAD-ONLY-THESE/`.
5. Generate with the strongest model available.
6. Do not ask it to create a landing page during setup.
7. Review the generated foundations and component language before using them in a project.

## Deliberately excluded

- React specimen and page layout.
- Manrope or any imposed font.
- Exact color tokens.
- Component names and dimensions.
- Card grids and report mockups.
- Prompt libraries and validation prompts.
- Historical website.
- Historical blue NutriWell brochure.
- Supplier proposals and workshop branding.
- Legacy multicolor logo.

## What success looks like

The output should feel authored rather than templated: premium editorial wellness, expressive but controlled, image-led, scientifically credible and recognizably EPI10. It should not reproduce the supplied PDF page-by-page or default to a generic SaaS component library.

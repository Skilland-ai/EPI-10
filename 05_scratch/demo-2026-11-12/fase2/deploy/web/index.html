Sobre este entorno

Es la instancia de laboratorio de OpenEMR con el módulo EPI10, con datos ficticios y dentro de un perímetro controlado, para que el equipo de EPI10 vea cómo sería el portal propio.

Son vistas simuladas: no es un servicio en producción y puede presentar algún error puntual.
